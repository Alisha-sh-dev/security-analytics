## About

This repository is a technical portfolio bringing together coursework, lab work, and an applied security internship completed while building toward a career in cybersecurity / security analytics. Each top-level folder is a self-contained set of projects with its own documentation, methodology, and findings.

## 🌟 Highlights

A few projects worth starting with if you're short on time:

- 🕵️ **[M57 Patents — Full DFIR Investigation](./digital-forensics)** - end-to-end forensic case: disk, memory, network, USB, registry, and timeline analysis with a final report
- 🎯 **[VulnHub Pentest Write-ups](./offensive-security)** - Kioptrix, Tr0ll, and MITM/SSL-stripping demos
- 🏦 **[Secure Digital Banking System](./cryptography)** - applied cryptography in a working transaction system
- 🏢 **[Ascend × Trillium Internship](./ascend-trillium-internship)** - applied security work in a real internship setting

## 📂 Repository Structure

| Folder | Focus | What's inside |
|---|---|---|
| [`ascend-trillium-internship`](./ascend-trillium-internship) | Applied Security (Internship) | JWT authentication vulnerability research & mitigation, SMB server hardening, C# file transfer tooling |
| [`offensive-security`](./offensive-security) | Penetration Testing | Lab-target write-ups (Kioptrix, Tr0ll), MITM — SSL stripping & ARP spoofing on Kali Linux |
| [`digital-forensics`](./digital-forensics) | DFIR | M57 Patents case investigation, real-world breach case studies (Canva, MyGov), ext4 analysis, MBR vs GPT analysis |
| [`cryptography`](./cryptography) | Applied Cryptography | Secure Digital Banking System (SDBS) - encrypted, authenticated transaction handling |
| [`network-engineering`](./network-engineering) | Networking | Cisco routing/switching, IPv4/IPv6 design, OSPFv3/RIPng implementation, performance analysis |
| [`computer-architecture-and-os`](./computer-architecture-and-os) | Systems / OS | Linux systems lab - file management, permissions, shell-level operations |
| [`data-science-projects`](./data-science-projects) | ML & Analytics | ECG arrhythmia detection, house price & medical insurance cost prediction, database/ERD design, applied ML coursework |
| [`risk-management`](./risk-management) | GRC | Risk assessment case studies - British Library, King Edward VII Hospital, University of the West of Scotland |

Each folder contains its own `README.md` with project-specific details.
