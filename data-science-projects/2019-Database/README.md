# Python Programming & Data Analysis Project

## 📖 Overview
This repository contains two parts:
- **Part A:** Python programming applications (loan eligibility, retail billing, employee performance evaluation).
- **Part B:** Data analysis of the **World Happiness Report 2019** dataset.

---

## 🧩 Part A – Python Applications
1. **Loan Eligibility System** – Nested conditionals for salary, employment, credit score, and loan status.  
2. **Retail Billing System** – Loops for itemized billing and tiered discounts.  
3. **Employee Performance Evaluation** – Functions & loops to grade employees (A/B/C) with bonus allocation.

---

## 📊 Part B – World Happiness Report 2019
- **Dataset:** 156 countries, factors: GDP, Social Support, Health, Freedom, Generosity, Corruption.  
- **Top 5 Happiest:** Finland, Denmark, Norway, Iceland, Netherlands.  
- **Bottom 5:** South Sudan, CAR, Afghanistan, Tanzania, Rwanda.  
- **Strongest Correlation:** GDP (r = 0.79).  
- **Weakest Correlation:** Generosity (r = 0.07).  
- **Regional Scores:** Oceania highest (7.27), Africa lowest (4.39).

---

## 🧠 Key Insights
- Economic prosperity, health, and social support drive happiness.  
- Generosity has minimal impact.  
- Policy focus: GDP growth, healthcare, social systems, anti-corruption.

---

## ⚙️ How to Run
1. Open **Google Colab** or Python IDE.  
2. Run `Part_A_Python_Programming.ipynb` for applications.  
3. Run `Part_B_World_Happiness_Analysis.ipynb` with `2019.csv` dataset.
